3. HELPER FUNCTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

resolveCategory(category):
  - null/undefined  → 'rice'  (default fallback)
  - string          → categorySlugMap[string] ?? 'rice'
  - object w/ .slug → categorySlugMap[category.slug] ?? 'rice'
  NOTE: categorySlugMap only has: rice, legumes, seeds, nuts, spices, sugar
        Any slug NOT in that map falls back to 'rice'.

resolveImageUrl(image):
  - null/undefined → undefined
  - string         → string (returned as-is)
  - object         → image.url ?? image.filename ?? undefined
  - anything else  → undefined

resolveSpecs(specs):
  - null/non-array → []
  - array          → each element mapped to:
      {
        label: { en, fa, ar }  // tries (spec.label)?.en, then falls back to spec.label ?? ''
        value: { en, fa, ar }  // tries (spec.value)?.en, then falls back to spec.value ?? ''
      }
  IMPORTANT: The Payload specs field is:
      type: 'array', localized: true
      with children: { label: 'text', value: 'text' }
  Since specs is an array of plain text fields (NOT objects), each spec
  element is a plain string when retrieved WITHOUT locale, or a string
  per locale when WITH locale. But the mapping assumes each spec element
  is an OBJECT with {label: {en,fa,ar}, value: {en,fa,ar}}.
  This is a MISMATCH — the mapping expects a structure that doesn't match
  what Payload actually returns for this schema shape.
