# Redesign GlobalMarkets Section — Premium & Consistent

## Problem
The GlobalMarkets section feels flat and inconsistent compared to other homepage sections. It's just bordered white cards with numbers — no ambient decoration, no gradient backgrounds, no premium effects.

## Design Direction

Match the premium language established by adjacent sections:
- **Signature Products**: Ambient blur blobs, gradient background fade
- **Value Props**: Edge fade masks, icon containers with gradient backgrounds, marquee
- **CTA**: Image ring insets, brand logo marquee with viewport mask

### What Changes

**1. Background — Add ambient decorative blobs** (like signature-products)
- Add two soft `blur-3xl` blobs (accent/5 and accent/3) behind the content
- Change from flat `bg-surface` to subtle gradient: `bg-linear-to-b from-surface via-surface to-surface`

**2. Section dividers — Match value-props pattern**
- Add top/bottom horizontal gradient lines:
  ```
  top:    bg-linear-to-r from-transparent via-brand-navy/25 to-transparent
  bottom: bg-linear-to-r from-transparent via-foreground/10 to-transparent
  ```

**3. Card redesign — More premium, less boxy**
- Replace the current plain bordered cards with a more refined design:
  - **Remove** the `border-b border-border/30` divider between number and title (feels mechanical)
  - **Add** a subtle gold accent line at the top of each card (thin 1px gradient)
  - **Improve** hover state: subtle lift + soft gold shadow
  - Keep `rounded-2xl` but add `shadow-sm` by default (not just on hover)

**4. Number presentation — Brand navy, refined**
- Use `text-brand-navy` for the number (matches the eyebrow color, feels grounded and premium)
- Keep `text-responsive-section font-semibold`

**5. Typography — Tighten hierarchy**
- Number: keep `text-responsive-section` (already good)
- Region title: keep `text-responsive-subheading` but add `font-semibold`
- Description: keep current style, already appropriate

**6. Staggered reveal — Keep existing pattern**
- The `animationDelay: ${idx * 100}ms` stagger is fine, keep it

### Key changes summary:
1. Added ambient blur blobs (matches signature-products pattern)
2. Added section dividers (matches value-props pattern)
3. Cards use `bg-background` instead of `bg-card/50` (cleaner)
4. Removed internal `border-b` divider — cleaner card interior
5. Added gold accent line on hover at top of card
6. Soft `shadow-sm` default, `shadow-md` on hover
7. Added `group-hover:-translate-y-1` micro-lift on hover
8. Number uses brand-navy color (matches eyebrow, feels grounded)
