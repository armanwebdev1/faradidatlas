# Final Polish / Production Readiness — Design Quality Audit

## Scope
Polish the existing design without changing visual appearance, branding, or information architecture. Focus on consistency, broken animations, and mobile experience.

## Critical Fixes (Bugs)

### 1. Hamburger Animation Bug
**File:** `components/layout/header/header-client.tsx`
**Issue:** `-translate-y-1/75` is not a valid Tailwind class. The bottom bar of the hamburger may not animate into the X shape correctly.
**Fix:** Replace with `-translate-y-[0.4375rem]` (7px, matching the gap between line 1 and line 3).

### 2. RevealSection is a No-Op
**File:** `components/shared/reveal-section.tsx`
**Issue:** Strips `opacity-0 translate-y-6` from className immediately, making elements always visible. Used by `GlobalMarkets`.
**Fix:** Rewrite to use IntersectionObserver like `AnimatedSection`, or remove the wrapper and use `AnimatedSection` directly.

### 3. CountUpValue Missing Reduced Motion
**File:** `components/about/count-up-value.tsx`
**Issue:** Does not check `prefers-reduced-motion`. Animates even when user prefers no motion.
**Fix:** Add `prefers-reduced-motion` check — show final value immediately if reduced motion is preferred.

### 4. SignatureProducts Missing Reduced Motion
**File:** `components/home/signature-products.tsx`
**Issue:** Autoplay runs regardless of `prefers-reduced-motion`.
**Fix:** Check `prefers-reduced-motion` before starting autoplay interval.

## Consistency Fixes (No Visual Change)

### 5. Consolidate Easing Tokens
**File:** `app/globals.css`
**Issue:** 5+ different easing values used across components. CSS defines `--ease-standard` and `--ease-emphasized` but components use hardcoded `cubic-bezier(0.22, 1, 0.36, 1)`, `cubic-bezier(0.4, 0, 0.2, 1)`, etc.
**Fix:** Add a third token `--ease-decelerate: cubic-bezier(0.22, 1, 0.36, 1)` for header/reveal animations. Map all tokens into `@theme inline` so Tailwind can use them. Do NOT change any component's actual easing — just make the tokens available.

### 6. Consolidate Shadow Tokens
**File:** `app/globals.css`
**Issue:** 26+ hardcoded shadow values in TSX bypass the 4 CSS shadow tokens. No visual change needed — just document the existing scale.
**Fix:** Add additional shadow tokens for the commonly used patterns (`--shadow-elevated`, `--shadow-floating`) in `@theme inline`. Do NOT change existing component shadows — just make tokens available for future use.

## Mobile Experience Fixes

### 7. Compact Header Brand on Mobile
**File:** `components/layout/header/header-client.tsx`
**Issue:** When header enters compact mode during scroll on mobile, the top brand hides but the compact brand is `hidden lg:flex` — so no brand is visible.
**Fix:** Show the compact brand on mobile too during compact mode. Change `hidden lg:flex` to `flex` on the compact brand, or keep the top brand visible on mobile.

### 8. Mobile Footer Collapsing
**File:** `components/layout/footer.tsx`
**Issue:** 6 sections stack vertically on mobile, making the footer very long.
**Fix:** Group navigation and product links into a single collapsible section on mobile, or reduce the footer to 2-3 essential sections on mobile with a "show more" toggle.

## Animation Cleanup

### 9. Remove Dead RevealSection
**File:** `components/shared/reveal-section.tsx`
**Fix:** If the IntersectionObserver fix from #2 is too invasive, simply remove the wrapper and have consumers use `AnimatedSection` instead. Only `GlobalMarkets` uses it.

### 10. Consolidate CountUp Implementations
**Files:** `components/shared/count-up.tsx`, `components/about/count-up-value.tsx`
**Issue:** Two separate count-up components with different animation approaches.
**Fix:** Keep `CountUp` (better implementation with rAF + cubic easing + reduced motion support). Update `CountUpValue` to use the same approach or replace its usage with `CountUp`.
