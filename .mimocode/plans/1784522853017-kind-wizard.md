# Plan: Homepage CMS 1:1 Mapping & Data Seeding

## Problem

The Homepage CMS global has fields for all sections, but:
1. **BrandShowcase ignores CMS data** — `brands` prop passed but never rendered
2. **Section-level text hardcoded** — eyebrows/titles/descriptions come from translations, not CMS
3. **Data not seeded** — CMS arrays empty, components use hardcoded fallbacks

## Step 1: Add Section-Level CMS Fields

**File**: `src/globals/Homepage.ts`

Add these groups to existing tabs:

### Value Props tab — add `valuePropsSection` group before `valueProps` array:
```
valuePropsSection (group):
  - eyebrow: text, localized
  - title: text, localized  
  - description: textarea, localized
```

### Brands & Products tab — add `brandsSection` group before `brandShowcase` array:
```
brandsSection (group):
  - eyebrow: text, localized
  - title: text, localized
  - description: textarea, localized
  - bannerImage: upload (relationTo: media), localized
```

### Markets & CTA tab — add `marketsSection` group before `globalMarkets` array:
```
marketsSection (group):
  - eyebrow: text, localized
  - titlePart1: text, localized
  - titlePart2: text, localized
  - description: textarea, localized
```

## Step 2: Fix BrandShowcase Component

**File**: `components/home/brand-showcase.tsx`

Rewrite to actually use CMS data:
- Read `brands` prop (from `homepage.brandShowcase`) — use each brand's `brandName`, `logo`, `description`
- Read `brandsSection` prop for section eyebrow/title/description/bannerImage
- Show brand logos in a grid or row (instead of static banner image)
- Keep fallback to current hardcoded defaults when CMS data is empty

## Step 3: Update ValueProps Component

**File**: `components/home/value-props.tsx`

- Add `section` prop accepting `{ eyebrow, title, description }`
- Read from `valuePropsSection` CMS group
- Fall back to translation strings when CMS data is empty

## Step 4: Update GlobalMarkets Component

**File**: `components/home/global-markets.tsx`

- Add `section` prop accepting `{ eyebrow, titlePart1, titlePart2, description }`
- Read from `marketsSection` CMS group
- Fall back to translation strings when CMS data is empty

## Step 5: Update Homepage Page

**File**: `app/(frontend)/[lang]/page.tsx`

Pass new section groups to components:
```tsx
<ValueProps lang={lang} items={valueProps} section={homepage?.valuePropsSection} />
<BrandShowcase lang={lang} t={t} brands={brandShowcase} section={homepage?.brandsSection} />
<GlobalMarkets lang={lang} markets={globalMarkets} section={homepage?.marketsSection} />
```

## Step 6: Seed CMS Data

**File**: `app/api/seed-homepage/route.ts` (create)

POST endpoint authenticated via PAYLOAD_SECRET. Seeds all homepage fields with current hardcoded fallback values:

- `valuePropsSection`: eyebrow="Why Faradid Atlas", title="Built for Continuity, Quality, and Trust", description="Our work is practical..."
- `valueProps`: 4 items (Globe/CheckCircle/Route/Package icons, titles, descriptions from defaultItems)
- `brandsSection`: eyebrow="Our Brands", title="Trusted names", description="Faradid Atlas..." (from translations)
- `brandShowcase`: 4 brands (Hayat, Golbanoo, Twenty One, Mizban) with logo uploads and descriptions
- `signatureProducts`: links to existing products by relationship
- `marketsSection`: eyebrow="Supply Footprint", titlePart1="Regional", titlePart2="Reach", description="Our network..."
- `globalMarkets`: 4 market cards with country, description, value from defaultMarkets
- `cta`: headline, description, buttonText, buttonUrl, image from translations
