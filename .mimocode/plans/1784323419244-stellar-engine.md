# Plan: Make About Page Fully CMS-Editable

## Overview

The about page already has a `company-info` Payload global with fields for most sections. Components accept `companyInfo` and fall back to hardcoded data. The task is to add the missing fields to the global, update components to read from CMS, seed all existing content, and generate a migration.

**Key principle**: Every visible piece of text on the about page must be editable through Payload CMS admin. After migration + seeding, the page must be visually identical to the current version.

## Current State

- **Global**: `src/globals/CompanyInfo.ts` — has 5 tabs (About, CEO, Values, Strategic Framework, Offerings & Content)
- **Fetcher**: `lib/fetch/company-info.ts` — passes `companyInfo` to all components
- **Page**: `app/(frontend)/[lang]/about/page.tsx` — passes `companyInfo` to all components except `JoinTeam`
- **Components**: 7 content components, each with hardcoded fallbacks

## Data Seeding

Create `scripts/seed-about.ts` — a one-time script that:
1. Connects to Payload via local API
2. Reads current hardcoded text from i18n files (`i18n/en.json`, `i18n/fa.json`, `i18n/ar.json`) and hardcoded fallbacks in components
3. Updates the `company-info` global with all content for all 3 locales (en, fa, ar)
4. Handles image uploads by creating media records for existing images (`/optimized/about-hero.webp`, `/ceo.webp`, etc.)

After seeding, the page must render **visually identically** to the current hardcoded version. This is the acceptance criterion.

## Implementation Order

1. `src/globals/CompanyInfo.ts` — Add all new fields and tabs
2. `npx payload generate:import` — Generate migration for new columns
3. `scripts/seed-about.ts` — Create seed script with all hardcoded content for all 3 locales
4. `components/about/hero.tsx` — Wire up `companyInfo.hero.*` reads
5. `components/about/what-we-offer.tsx` — Wire up `companyInfo.offeringsSection.*`
6. `components/about/team-showcase.tsx` — Wire up `companyInfo.valuesSection.*`
7. `components/about/join-team.tsx` — Accept `companyInfo` prop, wire up reads
8. `components/about/ceo-profile.tsx` — Wire up `companyInfo.ceo.connectorWord`
9. `app/(frontend)/[lang]/about/page.tsx` — Pass `companyInfo` to JoinTeam
10. `npx payload migrate` — Apply migration to production DB
11. Run seed script — Populate CMS with all existing content
12. `npx payload generate:types` — Regenerate TypeScript types
13. `npx payload generate:importmap` — Regenerate import map

## Constraints

- **No styling changes** — all components keep their exact same CSS/classes
- **No functionality changes** — animations, layout, responsive behavior untouched
- **Fallback chain**: CMS data → hardcoded default (preserves current look when CMS is empty)
- **Localization**: All text fields use `localized: true` for en/fa/ar
- **Visual identity after seeding**: Page must look identical before and after migration
- **Every visible text piece editable**: No hardcoded text remains the only source for any content

## Verification
