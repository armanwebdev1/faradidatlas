# Fix CMS Integration Regressions

Scope: Fix exactly 4 regressions from CMS migration. No refactoring, no new abstractions.

---

## Issue 1: All three languages render simultaneously

**Root cause:** `lib/fetch/products.ts` — the three fetch functions (`getProducts`, `getProductBySlug`, `getProductsByCategory`) accept a `locale` param but never pass it to `payload.find()`. Without `locale`, Payload returns localized fields as `{ en, fa, ar }` objects. The manual extraction into `nameEn/nameFa/nameAr` works for simple text fields, but nested localized structures (like `specs`) break — `resolveSpecs()` receives an object instead of an array, returning `[]`.

**Also:** `app/(frontend)/[lang]/products/[slug]/page.tsx:158-160` hardcodes `product.nameEn` / `product.aliasEn` / `product.descriptionEn` regardless of `lang`. The product detail page always shows English.

**Also:** `app/(frontend)/[lang]/faq/page.tsx:98` structured data uses `faq.questionFa` for Arabic (falls through).

**Fix — `lib/fetch/products.ts`:**
- Pass `locale` to all three `payload.find()` calls
- Increase `depth` from 1 to 2 (needed for gallery image resolution too)

**Fix — `app/(frontend)/[lang]/products/[slug]/page.tsx:158-160`:**
- Select name/alias/description based on `lang` instead of hardcoding English

**Fix — `app/(frontend)/[lang]/faq/page.tsx:98-101`:**
- Add Arabic branch to structured data question/answer

## Issue 2: Mega menu category thumbnails don't load

**Root cause:** `components/layout/header/header-client.tsx:114` — thumbnails come from `categoryProducts.find((p) => p.image)?.image`. If CMS products lack `featuredImage`, this is `undefined`.

**Fix — `components/layout/header/header-data.ts`:**
- Add a `categoryFallbackImages` map pointing to existing static images in `public/product_images/optimized/`

**Fix — `components/layout/header/header-client.tsx:114,156`:**
- Use `?? categoryFallbackImages[category]` and `?? typeFallbackImages[type]` as fallbacks

## Issue 3: Product detail pages show wrong information

**Root cause:** Same as Issue 1 — `page.tsx:158-160` hardcodes English fields.

**Fix:** Covered by Issue 1 fix above.

## Issue 4: Product images/gallery don't load

**Root cause:** `lib/fetch/products.ts` uses `depth: 1`. The `gallery` array contains nested `image` upload relationships at effective depth 2. With `depth: 1`, `gallery[].image` may only be an ID, not the full media object with `url`/`filename`.

**Fix — `lib/fetch/products.ts`:**
- Increase `depth` to 2 (same change as Issue 1)
